# OfficeQA synthetic HARD-question pilot (Phase-2)

`hard_synth_pilot_150.jsonl` — 150 truth-by-construction hard questions generated by
`scripts/officeqa/hard_question_gen.py` from the clean Treasury-Bulletin corpus
(`treasury_bulletins_clean.zip`). These are Phase-2 **training-candidate** questions; the real
133 hard questions remain the untouched held-out benchmark.

## Why these are trustworthy (truth by construction)
The answer is computed by us from the real table cells — no model produces it — so it is correct
by construction. Each record carries the full `golden_path` (every cited cell with its source
file, 0-indexed line, month, raw text and parsed value) so the answer is fully auditable.

Validation on this batch:
- **150/150** answers recompute exactly from the cited cells (independent re-derivation).
- **18/18** sampled cited cells found verbatim at their cited (file, line) in the corpus.
- Generator reproduces a real benchmark answer blind: "National defense, 1953 monthly sum" =
  **44,463** == benchmark UID0003, and within 2 of the table's own published Cal.-yr. total.

## Well-posedness (answer independent of which bulletin the agent finds)
Monthly tables reprint across bulletins with *revised* figures. We keep a (category, year) only
when **every** bulletin reporting it agrees on the full 12-value vector (a canonical cross-source
index). So the answer does not depend on which reprint the agent retrieves.

## Quality gates applied
- **Flow tables only**: table caption is an Expenditures/Receipts/Outlays statement (summing a
  monthly dollar flow is meaningful). Excludes debt-maturity/price-index/livestock/insurance tables.
- Clean categories: footnote markers (`2/ 3/`), cross-refs, quotes and parser dedup suffixes
  stripped; reject `col_N`, delta columns, unit-less ratios/rates/indexes, numeric-code/maturity
  leaves, and accounting-reconciliation lines (adjustment / clearing account).
- Real units taken from the `(In millions of dollars)` caption line.

Known residual: two categories carry corpus OCR artifacts (`Agricul-ture Depart-ment`,
`Bigway Trust Fund` = Highway). Faithful to the text the agent also reads; answers unaffected.

## Composition
- 150 questions, balanced 25 each across 6 templates: `year_sum`, `year_mean`, `halfyear_mean`,
  `year_geomean`, `two_year_diff`, `two_year_pct_change`.
- 37 distinct categories, years 1941–1968; 50 two-year questions span two source bulletins.

## Regenerate
```
python3 scripts/officeqa/hard_question_gen.py curate <corpus_dir> \
    --out officeqa_pilot_records/hard_synth_pilot_150.jsonl -n 150
# explore (dry-run print) / emit (all candidates) modes also available
```
Tests: `python3 -m unittest scripts.officeqa.tests.test_hard_question_gen`
